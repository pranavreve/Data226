# Data226 Finance Data Analytics

This repository contains resources for the Data226 Finance Data Analytics project, focusing on data extraction, transformation, loading (ETL), and analytics with tools such as Apache Airflow, DBT (Data Build Tool), and Apache Superset.

## Project Overview

The project demonstrates a finance data analytics pipeline, performing ETL operations on financial datasets, applying data transformations using DBT, and visualizing insights with Superset.

### Key Components

- **Airflow**: Orchestrates and automates the ETL workflows.
- **DBT (Data Build Tool)**: Transforms raw data into an analytics-ready format.
- **Superset**: Visualizes the processed data.
- **Logs**: Contains logs generated during the pipeline execution for monitoring and troubleshooting.
